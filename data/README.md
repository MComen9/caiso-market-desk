## 更新约定

更新数据需新增版本，记录来源、真实获取时间、交易日、时区和单位，并重新生成清单。
不得覆盖历史预测的发布时间、把缺失填成零，或把历史开发评估重新命名为独立测试。
日常扩展数据优先采用按版本的 GitHub Release 附件；不要持续把重复大包写入 Git 历史。

执行 `python3 scripts/verify-data.py` 验证整批公开数据；该命令不访问网络。
